# LIFEOS Android
Native Kotlin + Jetpack Compose starter app.
Build: GitHub Actions → Build LIFEOS APK → Run workflow.
Artifact: LIFEOS-debug-apk (contains app-debug.apk).
This is an initial starter build. Study topic completion and gym set counts are currently session-only; persistent history, camera journal, background Pomodoro notifications, detailed set/reps/weight logging, music integrations and backup remain future work.
